THE LAST RONIN — Windows build
==============================

HOW TO PLAY
  1. Unzip  TheLastRonin-Windows.zip
  2. Double-click  TheLastRonin.exe

That's all — the game's data is bundled inside the .exe, so no other files are needed.

If Windows shows a blue "Windows protected your PC" box (it does this for any app
that isn't code-signed), click "More info" -> "Run anyway". This is normal and safe
for an indie / game-jam build.

CONTROLS
  Move ............... W A S D  or  Arrow keys
  Interact / talk /
  read / continue .... E   (or Enter)
  Pick an option ..... Up / Down, then E / Enter

The game plays start to finish. It opens in a window (may start maximized).

Built with Godot 4.7.1 (64-bit Windows).
