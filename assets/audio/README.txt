Background music goes here.

Save the track as exactly one of these names (the game tries them in this order):

    bamboo_serenity.ogg      <- best for seamless looping
    bamboo_serenity.mp3
    bamboo_serenity.wav

Source: https://pixabay.com/music/meditationspiritual-bamboo-wind-serenity-497194/

It is loaded and looped automatically by the Music autoload (scripts/systems/music.gd),
plays across every scene, and fades out at the grave. If the file is missing, the game
simply runs without music — nothing breaks.
